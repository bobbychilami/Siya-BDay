SIYA ENVELOPE ANIMATION — PNG ASSET PACK

PNG ONLY. No GIFs, no video, no animated files.

Included:
- Full-screen closed envelope base (portrait 9:16).
- Separate artwork PNG references: ribbon/bow, wax seal, open-envelope reference, card border, seaside scene, lemons, florals, olive branch, and decorative objects.
- Full asset sheet for composition reference.
- Previously cropped storyboard reference images (low-resolution concept references only).

Important limitations:
- The component artwork is separate PNG artwork, but several components have their own painted background or are not production-aligned cutouts. They are visual references, not guaranteed pixel-perfect transparent layers.
- The storyboard crops are NOT smooth animation frames and are NOT intended to be played as a frame sequence.
- Do not create animation by switching/crossfading these reference images.

Recommended Freebuf workflow:
1. Use 01_closed_envelope_fullscreen_9x16.png as the full-viewport mobile opening canvas.
2. Recreate/derive clean aligned layers in the project: envelope body, front pocket, hinged flap, ribbon strip, bow loops/tails, seal, inside coastal reveal, invitation card, decorative florals.
3. Keep each layer aligned on the same viewport/canvas coordinate system; use transparent PNGs where possible and SVG/CSS shapes for geometry if needed.
4. Animate actual layer transforms with GSAP (ribbon loosen/release, seal release, flap rotate on hinge, inner reveal, card lift/settle).
5. Keep the mobile composition edge-to-edge and 9:16; adapt desktop separately without shrinking the envelope into a small object.

This ZIP is an asset/reference pack—not a finished animation and not a set of interpolated animation frames.
